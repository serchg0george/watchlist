# Что посмотреть

Трекер фильмов, сериалов и шоу для двоих, S и L: у каждого своя оценка 1–10, комментарии с ответами и реакциями, общая статистика. Сайт: <https://serchg0george.github.io/watchlist/>.

## Интерфейс

Вкладки: «Список», «Просмотрено», «Брошено», «Статистика». В «Списке» два фильтра: «Все» — то, что хотим посмотреть, и «Смотрим»; перенос в «Смотрим» убирает элемент из «Все». «🎲 Что посмотреть сегодня?» выбирает случайный элемент из «Все» с учётом фильтра по типу.

## Доступ на запись

Смотреть список может любой, редактировать — только владелец и коллаборатор с правом записи в репозиторий. Владелец создаёт fine-grained токен только для `serchg0george/watchlist` с правом Contents: Read and write, коллаборатор — classic-токен со scope `public_repo`. Токен вставляется через ⚙ и хранится только в браузере; владелец становится S, второй логин — L.

Для поиска по TMDB в ⚙ вставляется API Read Access Token, он тоже хранится только в этом браузере.

## Данные

Список лежит в `data/movies.json`, сайт записывает его через GitHub API токеном пользователя. Каждый элемент содержит `title`, `type`, `status` (`planned`, `watching`, `watched`, `dropped`), `ratings` `{S, L}`, `comments`, `replies`, `reactions` (`{цель: {S: [виды], L: [виды]}}`), необязательные метаданные `tmdb` и даты `addedAt`, `watchedAt`, `droppedAt`.

Код живёт в `master`, данные — в недельных ветках `data/YYYY-MM-DD_YYYY-MM-DD`; `Deploy Pages` берёт `data/movies.json` из текущей ветки `data/*`. `Weekly rollover` в понедельник около 00:05 по `Europe/Sofia` сводит прошедшую неделю одним коммитом в `master` и открывает новую ветку. При конфликте нужные изменения переносятся вручную в ветку текущей недели; старые ветки не переписываются.

## Телефон и локальный запуск

Сайт ставится на телефон как приложение («Установить приложение» в Chrome, «На экран „Домой“» в Safari) и без сети показывает последнюю загруженную версию.

```sh
python3 -m http.server
```

Затем открыть <http://localhost:8000>.
