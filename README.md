# Что посмотреть

Личный трекер фильмов, сериалов и шоу для двоих — S и L. Список «хочу посмотреть», отметки просмотренного, у каждого просмотренного две отдельные оценки 1–5 (S и L) и статистика по каждому и вместе. Данные хранятся в файле `data/movies.json` этого репозитория; сайт коммитит их через GitHub API с токеном пользователя.

Сайт: <https://serchg0george.github.io/watchlist/> (репозиторий `serchg0george/watchlist`, ветка `master`).

Все могут **смотреть** список без входа. **Редактировать** могут только люди с правом записи в репозиторий — через токен, который один раз вставляется в настройках сайта.

## Как редактировать

1. Создайте персональный токен GitHub (Settings → Developer settings → Personal access tokens):
   - **владелец репозитория** — Fine-grained tokens → Generate new token; Repository access: только `serchg0george/watchlist`; Permissions: **Contents — Read and write**;
   - **второй человек (коллаборатор)** — Tokens (classic) → Generate new token (classic); scope только **`public_repo`**. Fine-grained токен коллаборатору не подходит: GitHub пускает его только в репозитории его собственного аккаунта.
2. Откройте сайт, нажмите ⚙ в шапке, вставьте токен в поле «Токен» и нажмите «Сохранить». Кто вы, сайт определит по логину: владелец репозитория (`serchg0george`) — S, любой другой логин с правом записи — L (константа `OWNER_LOGIN` в `app.js`). Звёзды можно ставить только в своей строке; чужая оценка видна рядом, но не редактируется. Так же и с комментариями: под элементом кнопка «💬 Комментарий» для своего комментария, чужой виден, но не редактируется.

Сайт проверит токен запросом к `GET /user`, запомнит ваш логин (в `localStorage`) и покажет его в шапке: «Редактирует: \<логин\>». После этого появляются форма добавления, чекбоксы, звёзды и кнопка редактирования ✎. Кнопка «Выйти» удаляет токен из браузера.

Токен хранится только в `localStorage` вашего браузера и никуда не отправляется, кроме запросов к GitHub API от вашего имени.

## Удобства

- **Установка на телефон.** Android/Chrome: меню → «Установить приложение». iPhone/Safari: «Поделиться» → «На экран „Домой“». Открывается без адресной строки; без интернета показывается последняя загруженная версия списка.
- **«🎲 Что посмотреть сегодня?»** — случайный элемент из «Хочу посмотреть» с учётом фильтра по типу; строка подсвечивается.
- **Отмена.** После отметки «просмотрено» и удаления 5 секунд доступна кнопка «Отменить».
- **Дубли.** При добавлении названия, которое уже есть в списке (без учёта регистра, «ё» и знаков препинания), сайт спросит подтверждение.

## Как дать доступ второму человеку

1. В репозитории: Settings → Collaborators → Add people — добавьте его аккаунт (права записи).
2. Он принимает приглашение, создаёт свой classic-токен со scope `public_repo` (см. выше) и вставляет его через ⚙ на сайте.

Каждое изменение коммитится от имени того, чей токен использовался; поле `updatedBy` у изменённого элемента хранит логин автора (видно во вкладке «Статистика» → «Кто отметил»).

## Схема данных `data/movies.json`

Файл имеет вид `{ "version": 1, "items": [ Item, ... ] }`. Поля элемента:

| Поле        | Тип                          | Описание                                                        |
| ----------- | ---------------------------- | --------------------------------------------------------------- |
| `id`        | string                       | Уникальный идентификатор (для новых — `crypto.randomUUID()`)    |
| `title`     | string                       | Название                                                         |
| `type`      | `"movie" \| "series" \| "anime" \| "show"` | Тип: фильм, сериал, аниме, шоу/офлайн          |
| `status`    | `"planned" \| "watching" \| "watched" \| "dropped"` | Статус: хочу посмотреть, смотрим, просмотрено, брошено |
| `ratings`   | `{ "S": 1..5 \| null, "L": 1..5 \| null }` | Оценки двух зрителей, S и L, каждая отдельно          |
| `comments`  | `{ "S": string, "L": string }` | Комментарии двух зрителей, каждый пишет только свой (пустая строка — нет комментария) |
| `note`      | string                       | Заметка (может быть пустой)                                      |
| `addedAt`   | `"YYYY-MM-DD"`               | Дата добавления                                                  |
| `watchedAt` | `"YYYY-MM-DD"` или `null`    | Дата, когда отметили просмотренным                               |
| `updatedBy` | string                       | GitHub-логин последнего, кто менял элемент (или пустая строка)   |

## Запуск локально

В корне репозитория:

```sh
python3 -m http.server
```

и открыть <http://localhost:8000>.

## Замечание про GitHub Pages

Публичная страница на GitHub Pages обновляется примерно через минуту после сохранения (время деплоя). Редактор же всегда читает свежие данные напрямую через GitHub API, поэтому у вошедшего пользователя изменения видны сразу.
